# Clínica Aurora — site de exemplo

Site de demonstração para clínicas de estética. Todo o conteúdo (nome, endereço, horários, procedimentos) é **fictício** e as imagens são **ilustrativas, geradas por IA**.

Arquivo único `index.html` (HTML, CSS e JS) + pasta `img/`. Os dados editáveis ficam no bloco `CONFIG` no fim do arquivo.
